# Legacy React App Audit (pre-Solid 2 rewrite)

## 1. Purpose and scope

This document audits the local repository clone at `alltvcnl/` (legacy React 18 + Vite 8 + Electron 44 IPTV player) before a planned rewrite to Solid 2. The audit is static: it covers tracked source, configuration, CI, public assets, and planning files in this clone; no running app, network service, or release artifact was exercised. Findings cite exact paths and line numbers so they can be verified and mapped to migration work. Severity reflects security and correctness impact on the rewrite, not a formal CVSS score.

## 2. Critical findings

| Severity | Category | File:line | Problem | Impact | Fix direction |
| --- | --- | --- | --- | --- | --- |
| Critical | Electron sandbox | `electron-main.js:17-18` | `app.commandLine.appendSwitch("no-sandbox")` is applied globally to work around Linux permission issues. | Disables the Chromium OS-level sandbox for all renderer processes; any renderer compromise gains host-level reach. | Remove the switch; fix the underlying Linux packaging/permissions issue instead. |
| Critical | Electron webPreferences | `electron-main.js:26-34` | `webSecurity: false` (29), `allowRunningInsecureContent: true` (30), `experimentalFeatures: true` (31), `sandbox: false` (34). | Same-origin protections and mixed-content blocking are disabled; HTTP streams and experimental APIs can execute against the app origin. | Set `webSecurity: true`, drop insecure-content and experimental flags, keep `sandbox: true`, `contextIsolation: true`, `nodeIntegration: false`. |
| Critical | Network / CORS | `electron-main.js:45-71` | Global `webRequest` filter `*://*/*` rewrites `Origin`/`Referer` to `"*"` (51-52) and injects `Access-Control-Allow-Origin: ["*"]` (64) with `Access-Control-Allow-Credentials: ["true"]` (67) on every response. | Any origin is granted credentialed cross-origin reads, defeating CORS as a security boundary across the entire session. | Scope interception to explicit stream hosts, preserve real origin/referer, and never combine wildcard ACAO with credentials. |

## 8. Migration requirements derived from findings

| Area | Requirement |
| --- | --- |
| Security | Keep Electron sandbox and `webSecurity` enabled; remove global CORS/header injection; add CSP; external links via allowlisted `shell.openExternal` with `rel`; validate URLs and storage input; consent-gate or remove GA; preserve the no-`eval`/no-`dangerouslySetInnerHTML` property. |
| Build | Valid SemVer version; correct icon path; reproducible `npm ci` build without `prune`/`postpackage` mutation; include production deps in packaged output; resolve `__dirname` in ESM or delete dead Zustand aliases/submodule; CI Node version compatible with the build tool; route-driven sitemap generator. |
| Runtime | One canonical bookmark schema/key with migration; validated/clamped persisted numbers; one guarded fetch primitive with abort and generation counters; no `setState` during render; one active HLS player with teardown; path-based routing with explicit empty/error states; centralized, env-driven endpoints with safe proxy URL encoding. |
| Performance | Route-level lazy loading; virtualized/lazy-mounted channel lists; shared pagination implementation; cached/parsed bounded data instead of repeated ~1.5 MB fetches; cache headers for JSON/images; consistent layout/expand components. |
| SEO | Path-style URLs aligned with canonicals, OG/Twitter tags, and sitemap; single non-fabricated JSON-LD graph; valid canonical query serialization; head tags emitted before early returns; SearchAction template matching real routes. |
| Accessibility | Real buttons with labels/aria, no nested interactive elements, associated form labels/IDs, keyboard-operable icon actions, honest toggle labels/icons, and functional or removed placeholder controls. |
| Testing | Introduce a test script/runner; port the identified bug list (search page index reset, `/10` page math, bookmark key migration, canonical generation, storage corruption handling, provider validation) into regression tests before and after the Solid 2 rewrite. |
